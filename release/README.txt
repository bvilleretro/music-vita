MUSIC VITA  v1.0   by Bville Retro
A music player for the PlayStation Vita (MP3 + WAV).
Needs a Vita with homebrew enabled (custom firmware).

INSTALL
1. Copy MusicVita-v1.0.vpk to the Vita (VitaShell USB or FTP) and install it from VitaShell.
2. Copy your music to  ux0:data/MusicVita/  (drag and drop).
3. Open Music Vita from the LiveArea.

CONTROLS
X            play the selected song / confirm
O            pause / resume
L / R        previous / next (L restarts the song if it has played 3 seconds)
D-pad U/D    volume
D-pad L/R    rewind / fast-forward (hold to skim)
Sticks       move around menus
Triangle     switch screen: List, Tiles, Playlists, Settings
Square       cycle the visualizers
Select       lyrics on / off
Start        screen off (music keeps playing, any button wakes it)
Close the app with the PS button.

LYRICS
Embedded lyrics in the MP3 are used automatically. You can also put a
Song.lrc (timed) or Song.txt (plain) next to Song.mp3 in the music folder.

COVER ART
Embedded JPEG and PNG covers are used. If a song has none (or a format that
is not supported), put Song.jpg next to it, or one cover.jpg for the folder.

PLAYLISTS
Create them in the Playlists screen. They are saved as .m3u files in
ux0:data/MusicVita/playlists/ and can be edited on a PC.

THEMES
Settings > Theme has eight premade colors plus Custom (ux0:data/MusicVita/theme/).

NOTES
- Pressing the power button or the PS button suspends the app (Vita limitation).
- WebP, GIF and BMP covers are not supported.
